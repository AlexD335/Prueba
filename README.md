# 🏪 Gestión de Tienda

Proyecto de prueba para practicar Git y GitHub.

## 📋 Descripción

Este proyecto consiste en una aplicación sencilla para gestionar una tienda.

## 🚀 Funcionalidades

- Agregar productos
- Consultar productos
- Actualizar productos
- Eliminar productos
- Gestionar inventario

## 💻 Tecnologías

- TypeScript
- Node.js
- Git
- GitHub
